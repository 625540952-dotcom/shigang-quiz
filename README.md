# 中国近现代史纲要 · 平时测验题库

把扫描版《中国近现代史刚要平时测验.pdf》整理成的刷题应用，共 **181 道单选题**。

在线使用：<https://625540952-dotcom.github.io/shigang-quiz/>

## 功能

- **顺序刷题** —— 按题号顺序过一遍，可跳转到任意题号
- **答题总览** —— 全部 181 题的题号格，绿色=做对、红色=做错、灰色=没做过；
  可按 **全部 / 答对 / 答错 / 未作答** 筛选，点题号从该题开始重做，
  筛到「答错」时还能一次把整组错题重做一遍
- **错题本重做** —— 答错自动收录，重新做对后自动移出；点任意一道即从该题起
  往后刷整个错题本
- **随机组题 50** —— 每次从 181 题里随机抽 50 道，做完出正确率

每题作答后立即显示对错和答案解析。答对后会停留约 1.2 秒再自动进入下一题
（首页可关闭该开关；答错不自动跳，留时间看解析）。

## 手机上使用（iPhone / iPad）

1. Safari 打开上面的网址
2. 点底部的「分享」按钮 → **添加到主屏幕**
3. 之后从桌面图标进入，全屏显示、没有地址栏，和原生 App 一样

页面带 Service Worker，**第一次打开后即可离线刷题**（地铁、断网都能用）。

## 进度保存

- 在线访问时，对错状态、错题本、答题进度和统计自动存在浏览器本地
- 进度**按网址隔离**：电脑上双击 `index.html`、手机上访问网页版，两者进度互不相通
- 需要换设备时，用首页的「进度存档」导出存档码，在另一台设备上粘贴导入
  （旧版存档码仍可导入，只是不含"做对过"的记录）
